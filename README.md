# 📸 SnapSync — Virtual Photobooth & Connectivity for LDR Couples

**SnapSync** is a web-based application designed to bridge the distance between couples and long-distance partners. It provides an interactive space where couples can hang out, enjoy real-time video calls, play mini-games, send messages, and capture synchronized photobooth memories together in real time.

---

## ✨ Key Features

* 🎥 **Real-time Live Video Call:** Seamless 1-on-1 video and voice connection tailored for long-distance partners.
* 📸 **Synchronized LDR Photobooth:** Take photos together virtually with real-time countdowns, custom filters, and interactive photo strip frame templates.
* 🎮 **Mini-Games:** Interactive games designed for couples to play while on call to pass time and build connection.
* 💬 **Instant Messaging:** Chat directly within the app during session calls or photobooth sessions.
* 🔒 **User Authentication & Profiles:** Secure account management and personalized profile pages powered by Supabase.

---

## 🛠️ Tech Stack

* **Frontend:** React.js, Vite, HTML5, CSS3 (Glassmorphic & Responsive UI)
* **Real-time Video / Peer Connection:** PeerJS / WebRTC
* **Backend & Database:** Supabase (Auth & Database)
* **Deployment:** Vercel
